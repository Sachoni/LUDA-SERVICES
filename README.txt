LUDA SERVICES WEBSITE
=====================

Files:
- index.html  : Website content and page structure
- style.css   : Black/red styling and responsive layout
- script.js   : Mobile menu, service selection, date validation and WhatsApp booking request

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open the luda-services-website folder.
3. Double-click index.html to preview it in your browser.

BEFORE PUBLISHING
1. Open script.js in VS Code.
2. Replace WHATSAPP_NUMBER = "2547XXXXXXXX" with the client's real WhatsApp number.
   Use country code 254 followed by the 9-digit Kenyan mobile number, without + or spaces.
3. Confirm the service list, prices, opening hours, location, business description and contact details with the client.
4. Replace the "ADD CLIENT PHOTO HERE" placeholder with the client's real photo.
5. Replace the text logo with the client's logo when it becomes available.

BOOKING LIMITATION
This is a front-end website. Once a real WhatsApp number is configured, the booking form prepares a message and opens WhatsApp for the customer to send. The appointment is not confirmed automatically, and no booking database/admin dashboard is included.
